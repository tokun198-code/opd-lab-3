Документация проекта: Castlevania Chrome Dino Game

Назначение проекта

Проект представляет собой модифицированную версию классической игры Chrome Dino, выполненную в сеттинге Castlevania на движке Godot Engine. Это версия на .NET и языке C#. Игрок управляет персонажем, который преодолевает препятствия и сражается с зомби и летучими мышами.
